# Kuuli-veebileht

[link](https://kodu.ut.ee/~katlerova/www/koduleht.html)

Selle veebilehe eesmärk on aidata sul leida just sulle sobivaim meeskonnasport Eestis — olgu selleks jalgpall, võrkpall või korvpall.

Me toome välja iga spordiala eripärad, treeningvõimalused ja eelised, et sa saaksid teha teadliku valiku vastavalt oma eesmärkidele, füüsilisele vormile ja eelistustele.
